# skyscanner-oneliner

Summarizes Skyscanner flight pages into compact one-liners.

## Overview

Paste the text of a Skyscanner flight results page and get a condensed summary like:

```
170 €
 8 marco: FAO  6:05 ->  6:55 LIS | LIS  8:40 -> 12:50 AMS
10 marco: AMS 17:50 -> 20:15 LIS | LIS 23:00 -> 23:50 FAO
```
